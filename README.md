# Student Management System

## Project Description
The Student Management System is a console-based Java application used to manage student records. It allows users to add, view, search, update, and delete student information.

## Objectives
- To learn object-oriented programming in Java.
- To manage student records efficiently.
- To practise file handling and exception handling.
- To understand interfaces, collections, and multithreading.

## Features
- Add new student records
- View all students
- Search students using Student ID
- Update student details
- Delete student records
- Save and load records using a text file
- Display total students and average marks using a separate thread
- Prevent duplicate Student IDs

## Project Structure
- `Student.java` – Stores student details.
- `StudentOperations.java` – Defines student operations.
- `StudentManager.java` – Manages student records.
- `Task_6_Final.java` – Contains the main menu.
- `FileHandler.java` – Saves and loads student records.
- `StudentSummaryThread.java` – Calculates the student summary in a separate thread.
- `students.txt` – Stores saved student records.

## How to Run
1. Open the project in Eclipse.
2. Ensure all Java files are in the `week_6` package.
3. Run `Task_6_Final.java` as a Java Application.
4. Select an option from the console menu.
5. Follow the instructions to manage student records.
